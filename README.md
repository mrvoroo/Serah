# منصة رحلة مع الأنبياء (Serah)

منصة بسيطة لمحاضرات الأطفال: أرشيف محاضرات صوتية مع صور تتغير تلقائيًا، نجوم وترتيب، اقتراحات، وبوت تيليجرام للمعلمات.
قاعدة البيانات: Google Sheets — الملفات: Google Drive — الواجهة: صفحة ويب تُنزَّل كتطبيق (PWA) على GitHub Pages.

## الهيكل
- `backend/` كود Google Apps Script (الجداول، الدخول، البوت، رفع الملفات الكبيرة)
- `web/` واجهة التطبيق (بدون أي مكتبات)

## خطوات التشغيل (مرة واحدة)

### 1) الشيت والسكريبت (حساب جوجل الخاص بالمشروع)
1. أنشئ Google Sheet جديد باسم `Serah_DB`.
2. من القائمة: Extensions ← Apps Script. (ستجدها بالعربي: إضافات ← Apps Script).
3. انسخ محتوى `backend/Code.gs` مكان الكود الموجود، وفعّل إظهار ملف `appsscript.json` من Project Settings ثم الصق محتوى `backend/appsscript.json`.
4. شغّل الدالة `setup` (وافق على الصلاحيات). ستنشئ الجداول ومجلدات درايف.
5. من Project Settings ← Script Properties أضف:
   - `BOT_TOKEN` = توكن البوت (من بوت فاذر)
   - `SITE_ORIGIN` = أصل الموقع بدون مسار ولا شرطة في الآخر: `https://mrvoroo.github.io` ← ⚠️ يُكتب هنا فقط، وليس في الكود. (الخلفية تقبل أيضًا الشكل القديم `https://mrvoroo.github.io/Serah` وتفصل الأصل عن المسار بنفسها؛ درايف يرفض الرفع من المتصفح لو الأصل فيه مسار.)
6. عدّل رمز المعلمة داخل `seedFirstClass` ثم شغّلها مرة واحدة. ستجد كود الفصل في السجل (Logs).
7. Deploy ← New deployment ← Web app. Execute as: Me — Who has access: Anyone. انسخ الرابط (ينتهي بـ `/exec`).
8. شغّل الدالة `installPolling` (تنشئ مشغّلًا يسأل تيليجرام كل دقيقة؛ ويب هوك تيليجرام لا يعمل مع Apps Script)، ووافق على الصلاحيات.

### 2) الموقع
1. ضع رابط `/exec` في `web/config.js`.
2. في GitHub: Settings ← Pages ← Source: GitHub Actions. الموقع يُنشر تلقائيًا عند كل تحديث.

### 3) ربط معلمة بالبوت
أرسلي للبوت: `/start كود-الفصل` ثم ابعتي التسجيل الصوتي.

## الأمان
- لا يُكتب توكن البوت أو أي سر في الملفات. مكانه الوحيد Script Properties.
- كل ملف مرفوع يُشارَك بالرابط (لمن يملك الرابط فقط) ليعمل التشغيل للأطفال.
- المحاضرة تظهر للأطفال بعد اعتمادها من المراجعة الشرعية فقط (زر «اعتماد ونشر»).
